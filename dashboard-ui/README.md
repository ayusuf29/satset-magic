# Mobile Command Dashboard (Next.js)

Dashboard responsif untuk memantau status eksekusi agent secara real-time dan memberikan keputusan Human-in-the-Loop.

## Menjalankan Dashboard
1. Masuk ke direktori: `cd dashboard-ui`
2. Install dependencies: `npm install`
3. Jalankan server development: `npm run dev`
4. Buka `http://localhost:3000` di browser desktop atau browser smartphone.
